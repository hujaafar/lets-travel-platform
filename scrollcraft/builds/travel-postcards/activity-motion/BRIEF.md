# Activity and motion revision

The user explicitly requests more demo transactions/trips and motion always on, with stronger travel choreography. This extends the travel-postcards brief; it does not copy reference artwork.

The opening peak is now an expanding coastline and three postcards that separate into a travel-journal spread. Each postcard filters actual journeys. A plane follows the decorative route, the landscape responds slightly to a mouse, and in-view collection photographs breathe at an unhurried pace. Native scrolling, stable headline/actions, keyboard navigation, and mobile natural flow remain. Motion starts on each visit as requested; an explicit pause stops ambient animations and pinning for that visit. Hidden/offscreen hero animation pauses.

Data is explicitly fictional and opt-in: 18 new trips, 64 read-only demo bookings, 16 labeled reviews, 10 fictional people and 3 report scenarios. These are stored in the actual services/database for browsing and testing. Demo bookings contain no provider references and are excluded from payment reconciliation. Existing sandbox payment records and accounts are preserved. This user-authorized dataset replaces the original brief's prohibition on new sample records; labels must distinguish examples from provider settlements.

Device families: expanding landscape, independently floating/fanning postcards, flight route, staggered collection, destination wipe. Desktop/tablet/mobile compositions must preserve headline and action space. Working forms and ledger stay still.
