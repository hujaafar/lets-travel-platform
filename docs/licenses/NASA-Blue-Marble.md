# NASA Blue Marble texture

`dashboard/public/images/earth.jpg` is the 2048 × 1024 Blue Marble land, ocean, sea ice and clouds composite.

- Source image: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57735/land_ocean_ice_cloud_2048.jpg
- NASA source and credit: https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/
- Credit: NASA Goddard Space Flight Center. Image by Reto Stöckli; enhancements by Robert Simmon.
- NASA describes these images as freely available to educators, scientists, museums, and the public. No NASA insignia or endorsement is included.

The application projects the unmodified texture onto an original shader sphere. Decorative orbit geometry does not represent actual aircraft positions or route measurements. The texture is served locally and embedded in the portable preview; no NASA request occurs while using the interface.
